Background removal

Select any layers that have image fills — product shots, a logo, a photo in a frame — and cut the background out on-device. Nothing is uploaded and there is no per-image cost. The first run downloads about 18 MB of model and runtime, then it is cached for the session.

Model

Pick the u2netp.onnx file from disk — this always works and needs no deploy. It lives in your repo at public/models/u2netp.onnx. Chosen once per session.

Or load it over the network. This needs Access-Control-Allow-Origin on /models/ — see cors-patch.md. Without that header the browser blocks it.

Layer naming

Cirqle writes each sheet column to a layer named # + the column name, lowercased with spaces removed — #product, #offerprice, #mrp, #price1, #offerdatedisplay. Same convention as the Google Sheets plugin, so existing templates work unchanged.
