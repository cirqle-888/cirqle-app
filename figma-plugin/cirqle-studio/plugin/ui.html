▶How auto picks

Auto reads each product — price digits, paise, MRP, offer type, name language — and picks the variant that fits. Names like “Variant 2” are fine: Studio reads each variant's own sample instead, so the card showing 000 is used for 3-digit prices.

If a property isn't recognised, set Use: … yourself (✓ fits marks the ones that work) and aim each product group at a variant. Use: name language restyles all Malayalam or English names in one move.
